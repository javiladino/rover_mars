🗺️ PDS4 Product Naming Convention

-- PDS4 Logical Identifier format:
urn:nasa:pds:mars2020_mastcamz_sci_raw:data_imagedr:M20_MCZL_0001_0000700032_000RZL_N_01

-- Breakdown:
M20        = Mars 2020 mission
MCZL/MCZR = Mastcam-Z Left / Right
0001       = Sol number (4 digits)
0000700032 = SCLK (spacecraft clock, 10 digits)
000        = Filter position (0–7)
RZL        = Product type (RZL = Raw Zoom Left)
N          = Normal (vs. T = Thumbnail)
01         = Version

-- File extensions:
.IMG  = Binary image data (raw 12-bit DNs, big-endian)
.xml  = PDS4 label (Object Description Language v4)
.json = Calibrated metadata (Silver layer, simulation)

📐 Radiometric Calibration Chain

# NASA/MIPL Mastcam-Z calibration pipeline (simplified)

# Step 1: Bias subtraction
DN_corr = DN_raw - BIAS_DN                    # BIAS = 2047 (12-bit half-scale)

# Step 2: Dark current correction (temperature-dependent)
DN_dark = DN_corr - DARK_RATE × EXPOSURE_SEC   # DARK_RATE ≈ 0.12 DN/s @ 20°C

# Step 3: Flat-field correction (per-filter response map)
DN_flat = DN_dark / FLATFIELD_MAP[filter_id]   # 1648×1214 per-pixel factor

# Step 4: Absolute radiometric conversion
# Radiance: L = DN_flat × R_abs (W/m²/sr/nm)
L = DN_flat × R_abs[filter_id]

# Step 5: I/F conversion (irradiance factor, dimensionless)
# I/F = π × L / (E_sun_Mars × cos(θ_sun))
IOF = (π × L) / (E_SUN_MARS[wavelength_nm] × cos(θ_solar_incidence))

# I/F range: 0.0 (absorbing) to 1.0 (Lambertian perfect reflector)
# Mars surface: ~0.15–0.45 depending on dust and rock type

📦 CCSDS Space Packet Structure

CCSDS 133.0-B-2 · Primary Header: 6 bytes · Secondary Header: 16 bytes · Max payload: 65,528 bytes

Primary Header (6 bytes)

VER3 bits000
TYPE1 bit0=TM
SHF1 bit1
APID11 bits0x01A5 (L)
SEQ FLAGS2 bits11=STANDALONE
SEQ COUNT14 bits0–16383
DATA LENGTH16 bitstotal_bytes - 7

Secondary Header (16 bytes, simulation)

SCLK8 bytes (float64)Spacecraft Clock
SOL4 bytes (uint32)Mars sol number
WL2 bytes (uint16)λ in nm
CRC-162 bytesCCITT checksum

☁️ Estrategia híbrida de nube (cuenta AWS con crédito de estudiante)

El stack completo (Kafka, Airflow, Jupyter) es demasiado pesado y costoso para correr 100% en servicios "enterprise" gestionados con un crédito limitado. Por eso se adopta un modelo híbrido: cómputo con estado en un único EC2 self-managed, y servicios gestionados de AWS donde el costo marginal es bajo y la señal técnica es alta. Detalle completo de cada decisión en docs/ANALISIS_MODERN_DATA_STACK.md (ADR-011 a ADR-020).

🚀 Quick Start

# 1. Clone the repository
git clone https://github.com/javiladino/rover_mars
cd rover_mars

# 2. Copy the env template and set your own credentials (never commit .env)
cp .env.example .env
#    Generate a real Airflow Fernet key:
#    python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"

# 3. Start all services (Kafka, MinIO, PostgreSQL, Airflow, Grafana, dbt)
docker compose up --build -d

# 4. Wait for services to be healthy (~2 min)
docker compose ps

# Full step-by-step guide (Fases 1-6, incl. AWS): docs/GUIA_IMPLEMENTACION_MODERN_DATA_STACK.md

# 5. Airflow (ETL orchestration) — credentials from your .env
#    http://localhost:8080  →  $AIRFLOW_ADMIN_USER / $AIRFLOW_ADMIN_PASSWORD
#    DAG: mastcamz_full_pipeline

# 6. MinIO (Data Lake) — credentials from your .env
#    http://localhost:9001  →  $MINIO_ACCESS_KEY / $MINIO_SECRET_KEY
#    Buckets: mastcamz-raw | mastcamz-bronze | mastcamz-silver | mastcamz-gold

# 7. Grafana (Telemetry) — credentials from your .env
#    http://localhost:3001  →  $GRAFANA_ADMIN_USER / $GRAFANA_ADMIN_PASSWORD

# 8. JupyterHub (Notebooks) — token from your .env
#    http://localhost:8888  →  token: $JUPYTER_TOKEN

# 9. Kafka UI (Message inspector)
#    http://localhost:8085

# 10. dbt docs (lineage + catálogo de modelos)
#    make dbt-docs  →  http://localhost:8081

# Stop all services
docker compose down -v

🧪 Run Simulator Only

# Install dependencies
cd simulator
pip install -r requirements.txt

# Run 10 sols of Mastcam-Z imaging simulation
KAFKA_BOOTSTRAP=localhost:29092 \
MINIO_ENDPOINT=http://localhost:9000 \
SIMULATION_TOTAL_SOLS=10 \
SIMULATION_INTERVAL_SEC=2 \
python mastcamz_simulator.py
